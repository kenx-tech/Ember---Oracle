## 🚀 Getting Started

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm or bun

### Installation

1. **Clone or navigate to the repository root**:
   ```bash
   cd /path/to/project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file (or configure environment variables in your deployment host):
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
   *(Note: The server includes built-in Aetheric Fallbacks if an API key is not supplied or if rate limits occur.)*

4. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   The application will be served at `http://localhost:3000`.

5. **Build for Production**:
   ```bash
   npm run build
   ```
   This compiles the Vite frontend and bundles the Express server with `esbuild` into `dist/server.cjs`.

6. **Start the Production Server**:
   ```bash
   npm run start
   ```

## 📡 API Endpoints Reference

The Express backend (`server.ts`) exposes the following endpoints:

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/api/generate` | `POST` | Generates a new multi-section chronicle draft based on a prompt, attachments, and chosen Voice. |
| `/api/iterate` | `POST` | Rewrites or enhances an individual section or full canvas with inline suggestions. |
| `/api/proactive` | `POST` | Scans current document paragraphs to produce margin critiques and lore notes. |
| `/api/tarot` | `POST` | Interprets single-card or 3-card spreads relative to the active document content. |
| `/api/channel` | `POST` | Evokes Goetia spirits, Netjeru, or Gatekeeper Ken x Cripps with moon sympathy calculations. |
| `/api/norse` | `POST` | Generates runic castings combining Runes, Norse Gods, Realms, and Cosmic Concepts. |

## ⌨️ Keyboard Shortcuts & Canvas Controls

- `Enter`: Add a new paragraph below the current block.
- `Backspace` (on empty block): Remove block and focus preceding block.
- `Eye / EyeOff` in Header: Toggle Distraction-Free full-screen writing mode.
- `Inhale / Exhale` toggle in Sacred Geometry: Toggle breathing text overlay on/off during deep focus.
